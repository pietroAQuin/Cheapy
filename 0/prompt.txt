Also read this to contextualize yourself: We assign each LLM a quality score in [0, 1] used for model selection/weighting. The score is derived from existing public benchmarks (not our own vibes) so it's reproducible and defensible. It reflects peak capability (highest effort setting available per model).

Sources. We aggregate three independent leaderboards, each measuring a different axis of "quality":

Artificial Analysis Intelligence Index (v4.1.1) — https://artificialanalysis.ai/evaluations/artificial-analysis-intelligence-index
Automated capability benchmark. AA runs 9 fixed evaluations itself (GDPval-AA, Terminal-Bench, SciCode, Humanity's Last Exam, GPQA Diamond, CritPt, τ³-Banking, AA-Omniscience, AA-LCR) under standardized conditions, scores pass@1, and takes a weighted average scaled 0–100. Weighting is agentic-heavy: 34% agents, 24% coding, 24% scientific reasoning, 18% general. Answers the question: does it solve hard, verifiable tasks?
Agent Arena — https://arena.ai/leaderboard/agent
Real-world agentic performance. No voting. Every live "Agent Mode" session (with terminal/web/filesystem tools) is routed to a randomly chosen model, creating a randomized controlled trial. Causal inference ("causal tracing") then estimates each model's treatment effect vs. the average model across 5 signals (confirmed success, praise vs. complaint, steerability, bash recovery, tool hallucination). The headline metric is Net Improvement (percentage points vs. average). Answers: does using this model make real work turn out better?
Text Arena / LMArena — https://arena.ai/leaderboard/text
Human preference. Users get two anonymous responses to a live prompt and vote for the better one; scores come from a Bradley-Terry model with style control (removes the advantage of longer/prettier answers). Answers: do humans prefer its responses?

Why these three. They're not redundant — they measure partially independent things, and they disagree in informative ways (e.g., older Opus ranks below newer models on AA capability but above them on human preference). Three benefits:

Coverage: capability, real-world outcomes, and subjective preference are all part of "quality"; no single board captures all three.
Error cancellation: each board has its own bias (AA can be over-fit/STEM-heavy, Text rewards likeability, Agent reflects Arena's user mix). Because the biases differ, averaging dilutes the noise and reinforces the shared "real quality" signal.
Hard to game: a model can spoof one number, but the exploits differ across boards — leading all three requires being genuinely good at all three.
